# Competitive Programming Practice

Solutions to competitive-programming problems from contests and practice platforms.

## Contents

- **Advent of Code** — yearly puzzle solutions (2023 onwards)
- **HackerEarth Problems** — practice problems from HackerEarth's catalogue

## Languages

Mostly C++ and Python, with Java for some problems.

## Layout

Each platform has its own directory; problems are organised by year / contest / topic depending on the source.
